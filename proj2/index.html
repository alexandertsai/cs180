Part 1.1: Convolutions from Scratch

We implemented two versions of convolution using only numpy. The first uses four for loops: two over the image pixels and two over the filter. The second uses two for loops: for each pixel we take the patch of the image under the filter, multiply it by the filter, and sum.

Both versions flip the filter first, since that is the difference between convolution and cross-correlation. Both also pad the image with zeros, by half the filter size on each side, so the output has the same size as the input. The box filter is a 9x9 array of ones divided by 81, so its weights add up to one. 

def pad(image, pad_h, pad_w):
    h, w = image.shape
    new_h = h + 2 * pad_h
    new_w = w + 2 * pad_w
    padded = np.zeros((new_h, new_w))
    padded[pad_h : pad_h + h, pad_w : pad_w + w] = image
    return padded

def convolve_4loop(image, filter):
    filter = np.flip(filter)  # Ensure the filter is flipped.
    pad_h, pad_w = filter.shape[0] // 2, filter.shape[1] // 2
    padded_image = pad(image, pad_h, pad_w)
    output = np.zeros(image.shape)
    for row_idx in range(image.shape[0]):
        for column_idx in range(image.shape[1]):
            for f_h_idx in range(filter.shape[0]):
                for f_w_idx in range(filter.shape[1]):
                    output[row_idx, column_idx] += filter[f_h_idx, f_w_idx] * padded_image[row_idx + f_h_idx, column_idx + f_w_idx]
    return output

def convolve_2loop(image, filter):
    filter = np.flip(filter)  # Ensure the filter is flipped.
    pad_h, pad_w = filter.shape[0] // 2, filter.shape[1] // 2
    padded_image = pad(image, pad_h, pad_w)
    output = np.zeros(image.shape)
    for row_idx in range(image.shape[0]):
        for column_idx in range(image.shape[1]):
            mini_instance = padded_image[row_idx:(row_idx + filter.shape[0]), column_idx:(column_idx + filter.shape[1])]
            output[row_idx, column_idx] = np.sum(mini_instance * filter)
    return output

There is basically no difference from the SciPy output. The largest difference in any pixel is about 1e-15, which is just floating point error. However, SciPy is much faster. The two-loop version is about 12 times faster than the four-loop version, and SciPy is about 19 times faster than the two-loop version.

For the boundary, we fill with zeros, which is also what scipy.signal.convolve2d does by default with mode="same". That is why the two outputs match. One side effect is that the box filter result gets a little darker right at the border, since it averages in the zeros.

We convolved the cameraman with Dx and Dy to get the partial derivatives in x and y. The gradient magnitude at each pixel is the square root of (dx squared plus dy squared). It is large wherever the brightness changes quickly, which is where the edges are.

We tried thresholds from 0.1 to 0.33 and ultimately decided on 0.33. That is where the noise from the grass almost completely disappears, yet the outline of the person and the camera still more or less stays intact. Lower thresholds keep more of the edges but also keep a lot of the grass.

We created the Gaussian filter using cv2.getGaussianKernel (size 9, sigma 1.5) and multiplying it by its transpose to get a 2D filter. We blurred the cameraman with it and then repeated Part 1.2.

There are two main differences. One, the result is far less noisy. Two, the edges are far clearer and more continuous. This is because taking a derivative amplifies small pixel-to-pixel noise, and blurring first removes that noise before we take the derivative. The edges also come out a bit thicker, since the blur spreads them out. Because the blurred gradients are weaker, we could use a lower threshold of 0.1.

The DoG filters do the same thing, but in one step. We convolve the Gaussian with Dx and Dy first, and then convolve the image once with each result. Convolution is associative, so we can group the filters this way. We found that the largest difference between the two gradient magnitudes is 7.6e-16 (rather small). So they match. 

kernel_part = cv.getGaussianKernel(ksize=9, sigma=1.5)

Part 2.1: Image Sharpening

We blur the image with a Gaussian filter (size 9, sigma 1.5), which keeps the low frequencies. Subtracting the blurred version from the original gives us the high-frequency details. We then add those details back to the original, scaled by alpha, to sharpen it. A bigger alpha means more sharpening. 

G = gaussian_kernel(ksize=9, sigma=1.5)
taj_blur = filter_color(taj, G)
high = taj - taj_blur
sharpened_taj = taj + alpha * high

We can also do this in one convolution. The filter is (1 + alpha) times the identity filter minus alpha times the Gaussian. The identity filter just keeps the original pixel. This gives the same result as subtracting the blur and adding back the details. 

def unsharp_mask(image, alpha, gaussian):
    impulse = np.zeros_like(gaussian)
    impulse[gaussian.shape[0] // 2, gaussian.shape[1] // 2] = 1
    kernel = (1 + alpha) * impulse - alpha * gaussian
    return filter_color(image, kernel)

def low_pass(image, sigma):
    ksize = int(6 * sigma) | 1
    return filter_color(image, gaussian_kernel(ksize, sigma))

def high_pass(image, sigma):
    return image - low_pass(image, sigma)

def hybrid_image(im_low, im_high, sigma_low, sigma_high):
    return low_pass(im_low, sigma_low) + high_pass(im_high, sigma_high)

Part 2.3: Gaussian and Laplacian Stacks

We implemented the Gaussian and Laplacian stacks with simple for loops. The Gaussian stack starts with the original image, and each level after that is the original blurred with a bigger sigma (2, 4, 6, 8).

Each Laplacian level is L[i] = G[i] - G[i + 1]. That leaves the details between two Gaussian levels. The last level is L[4] = G[4], the blurriest Gaussian level. Adding up all the Laplacian levels gives back the original image. 

def gaussian_stack(image, levels, sigma):
    g_stack = [image]
    for level in range(1, levels):
        new_sigma = level * sigma
        g_stack.append(low_pass(image, new_sigma))
    return g_stack

def laplacian_stack(g_stack):
    l_stack = []
    for i, layer in enumerate(g_stack[:-1]):
        l_stack.append(layer - g_stack[i+1])
    l_stack.append(g_stack[-1])
    return l_stack

Part 2.4: Multiresolution Blending

If you just cut two images in half and stick them together, you get a hard line. If you fade between them over a wide area, the fine details of both images overlap and look like a ghost. The fix is to blend each level of detail separately. Fine details should switch over a narrow area, and the broad colors should fade over a wide area.

So we build a Laplacian stack for each image and a Gaussian stack for the mask. The mask gets blurrier at each level, which makes the fade wider for the coarser levels. At each level we take mask times the first image plus (1 minus mask) times the second image. Then we add up all the levels to get the final image.

We tried mask sigmas from 1 to 8 and ended up choosing 8, as that most closely replicated the oraple in Figure 3.42. Smaller values still showed a line down the middle. 

def blend(im_a, im_b, mask, levels, sigma, mask_sigma):
    l_a = laplacian_stack(gaussian_stack(im_a, levels, sigma))
    l_b = laplacian_stack(gaussian_stack(im_b, levels, sigma))
    g_mask = gaussian_stack(mask, levels, mask_sigma)
    l_blend = []
    for i in range(levels):
        l_blend.append(l_a[i] * g_mask[i] + l_b[i] * (1 - g_mask[i]))
    return np.sum(l_blend, axis = 0), l_a, l_b, g_mask

What I Learned

The most important thing I learned is that seemingly very simple ideas, such as splitting an image into Gaussian and Laplacian layers, can produce really powerful results. In a world where we are so focused on generating images with AI, it is honestly quite surprising that these traditional methods can still produce such funny and fascinating-looking things.
