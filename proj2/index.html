Part 1.1: Convolutions from Scratch

We implemented two versions of convolution using only numpy. The first uses four for loops: two over the image pixels and two over the filter. The second uses two for loops: for each pixel we take the patch of the image under the filter, multiply it by the filter, and sum.

Both versions flip the filter first and pad the image with zeros. We elected to use same instead of "full" for padding since that was just generally easier. The box filter is a 9x9 array of ones divided by 81.

def pad(image, pad_h, pad_w):
    h, w = image.shape
    new_h = h + 2 * pad_h
    new_w = w + 2 * pad_w
    padded = np.zeros((new_h, new_w))
    padded[pad_h : pad_h + h, pad_w : pad_w + w] = image
    return padded

def convolve_4loop(image, filter):
    filter = np.flip(filter)  # Ensure the filter is flipped.
    pad_h, pad_w = filter.shape[0] // 2, filter.shape[1] // 2
    padded_image = pad(image, pad_h, pad_w)
    output = np.zeros(image.shape)
    for row_idx in range(image.shape[0]):
        for column_idx in range(image.shape[1]):
            for f_h_idx in range(filter.shape[0]):
                for f_w_idx in range(filter.shape[1]):
                    output[row_idx, column_idx] += filter[f_h_idx, f_w_idx] * padded_image[row_idx + f_h_idx, column_idx + f_w_idx]
    return output # this line took a long time to think about

def convolve_2loop(image, filter):
    filter = np.flip(filter)  
    pad_h, pad_w = filter.shape[0] // 2, filter.shape[1] // 2
    padded_image = pad(image, pad_h, pad_w)
    output = np.zeros(image.shape)
    for row_idx in range(image.shape[0]):
        for column_idx in range(image.shape[1]):
            mini_instance = padded_image[row_idx:(row_idx + filter.shape[0]), column_idx:(column_idx + filter.shape[1])]
            output[row_idx, column_idx] = np.sum(mini_instance * filter)
    return output

We calculate that there is basically no difference from the SciPy output. However, SciPy is much faster. The two-loop version is about 12 times faster than the four-loop version, and SciPy is about 19 times faster than the two-loop version.

For the boundary, we fill with zeros, which is also what scipy.signal.convolve2d does by default with mode="same". That is why the two outputs match. One side effect is that the box filter result gets a little darker right at the border, since it averages in the zeros.

We convolved the cameraman with Dx and Dy to get the partial derivatives in x and y. The gradient magnitude at each pixel is seen as np.sqrt(dx**2+dy**2). It is large wherever there is a sudden change brightness - implying the existence of an edge.

We tried thresholds from 0.1 to 0.33 and ultimately decided on 0.33. This was where we deemed most of the grass noise to disappear while still maintaining the outline of the person and the camera. Lower thresholds keep more of the edges but also show too much noise.

We created the Gaussian filter using cv2.getGaussianKernel (size 9, sigma 1.5) and multiplied it by its transpose to get a 2D filter. We blurred the cameraman with it and then repeated Part 1.2.

There are two main differences. One, the result is obviously less noisy. Two, the edges are far clearer and more continuous. Blurring first averages out the noise from things like the grass. As a result, the finite difference operators only really respond to the important edges that we care about. The edges also come out thicker, since the blur spreads them over several pixels. This also lowers the gradient values, so a threshold of 0.1 was sufficient here.

The DoG filters do the same thing, but in one step. We convolve the Gaussian with Dx and Dy first, and then convolve the image once with each result. Convolution is associative, so we can group the filters as such. We found that the largest difference between the two gradient magnitudes is 7.6e-16 (negligible).

kernel_part = cv.getGaussianKernel(ksize=9, sigma=1.5)

Part 2.1: Image Sharpening

We blur the image with a Gaussian filter (size 9, sigma 1.5), which keeps the low frequencies. Subtracting the blurred version from the original gives us the high-frequency details. We then add those details back to the original, scaled by alpha, to sharpen it. A bigger alpha means more sharpening. 

G = gaussian_kernel(ksize=9, sigma=1.5)
taj_blur = filter_color(taj, G)
high = taj - taj_blur
sharpened_taj = taj + alpha * high

We can also do this in one convolution. The filter is (1 + alpha) times the identity filter minus alpha times the Gaussian. This gives the same result as subtracting the blur and adding back the details. 

def unsharp_mask(image, alpha, gaussian):
    impulse = np.zeros_like(gaussian)
    impulse[gaussian.shape[0] // 2, gaussian.shape[1] // 2] = 1
    kernel = (1 + alpha) * impulse - alpha * gaussian
    return filter_color(image, kernel)

Part 2.2: Hybrid Images

For each hybrid, we keep the broad shapes from one image and the fine details from the other. We can use Gaussian filter to keeps the low frequencies (the blurry version). If we subtract the Gaussian blur from an image, we get the high frequencies instead. The sigmas below are in pixels. A larger sigma means a lower frequency cutoff.

We first struggled with aligning Derek and Nutmeg. We used the provided alignment code and clicked on the eyes in both images, then cropped both to the same region. Once aligned, we low-pass filtered Derek and high-pass filtered Nutmeg, and added the two together.

To pick the cutoffs, we tried a grid of sigma values for both images and looked at each result up close and from far away. We picked sigma 10 for Derek and sigma 4 for Nutmeg. Up close you mostly see the cat, and from far away you mostly see Derek. 

def low_pass(image, sigma):
    ksize = int(6 * sigma) | 1
    g = cv.getGaussianKernel(ksize, sigma).ravel()
    return cv.sepFilter2D(image, cv.CV_64F, g, g, borderType=cv.BORDER_REFLECT).reshape(image.shape)

def high_pass(image, sigma):
    return image - low_pass(image, sigma)

def hybrid_image(im_low, im_high, sigma_low, sigma_high):
    return low_pass(im_low, sigma_low) + high_pass(im_high, sigma_high)

Part 2.3: Gaussian and Laplacian Stacks

We implemented the Gaussian and Laplacian stacks with simple for loops. The Gaussian stack starts with the original image, and each level after that is the original blurred with a bigger sigma (2, 4, 6, 8).

Each Laplacian level is L[i] = G[i] - G[i + 1]. That leaves the details between two Gaussian levels. The last level is L[4] = G[4], the blurriest Gaussian level. Adding up all the Laplacian levels gives back the original image. 

def gaussian_stack(image, levels, sigma):
    g_stack = [image]
    for level in range(1, levels):
        new_sigma = level * sigma
        g_stack.append(low_pass(image, new_sigma))
    return g_stack

def laplacian_stack(g_stack):
    l_stack = []
    for i, layer in enumerate(g_stack[:-1]):
        l_stack.append(layer - g_stack[i+1])
    l_stack.append(g_stack[-1])
    return l_stack

Part 2.4: Multiresolution Blending

If you just cut two images in half and stick them together, you get a hard line. If you fade between them over a wide area, the fine details of both images overlap. To fix this, we blend each level of detail separately. Fine details should switch over a narrow area, and the broad colors should fade over a wider area.

We build a Laplacian stack for each image and a Gaussian stack for the mask. The mask gets blurrier at each level, which makes the fade wider for the coarser levels as described above. At each level, we take (mask)(first image) + (1 - mask)(second image). Then we add up all the levels to get the final image.

We tried mask sigmas from 1 to 8 and ended up choosing 8, as this most closely replicated the oraple in Figure 3.42. Smaller values still showed a slight line down the middle. 

def blend(im_a, im_b, mask, levels, sigma, mask_sigma):
    l_a = laplacian_stack(gaussian_stack(im_a, levels, sigma))
    l_b = laplacian_stack(gaussian_stack(im_b, levels, sigma))
    g_mask = gaussian_stack(mask, levels, mask_sigma)
    l_blend = []
    for i in range(levels):
        l_blend.append(l_a[i] * g_mask[i] + l_b[i] * (1 - g_mask[i]))
    return np.sum(l_blend, axis = 0), l_a, l_b, g_mask

What I Learned

The most important thing I learned is that seemingly very simple ideas, such as splitting an image into Gaussian and Laplacian layers, can produce really powerful results. In a world where we are so focused on generating images with AI, it is honestly quite surprising that these traditional methods can still produce such funny and fascinating-looking things.
